# Not in the pipeline

Everything here was built or recorded during the project but is not used by the working product: capture, session UI, Muse dialogue, drawings, explosion view and assembly help. Nothing in the pipeline imports it.

It is kept as a record, not maintained. Most of it was moved here unchanged, so paths to modules outside this folder (for example `calibration/`) are broken and its tests are not expected to run from here. Evidence folders hold records of earlier experiments and establish no general accuracy.
